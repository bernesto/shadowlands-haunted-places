# Published catalog

`haunted_places.csv` is the complete geocoded Shadowlands claims dataset used to
build the AI Ghost Hunter on-device catalog. It is mirrored from the CC0
TidyTuesday 2023-10-10 distribution and retains the original descriptive text.

Applications must treat every row as an unverified third-party claim, preserve
source attribution, and independently determine whether a location is public,
open, and appropriate to visit.
